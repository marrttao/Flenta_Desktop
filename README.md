# Flenta Bank

Админ-панель: /admin (Overview), /admin/clients (Clients).
Реализация находится в src/features/admin: api, model, ui; новые компоненты — TSX,
стили — CSS Modules. Для проверки: npm test, npm run typecheck, npm run lint,
npm run build. Запуск разработки: npm run dev.

Доступ проверяет backend по подтверждённой сессии и app_metadata.role = admin.
Сохранённый во frontend признак isAdmin используется только для ссылки навигации.
Переход на /admin без сессии открывает обычный вход с возвратом в админку.
Клиентская проверка не заменяет серверную; произвольные returnTo не используются.

Overview показывает счётчики и последние семь операций в UTC. Clients поддерживает
поиск по email, серверную пагинацию по восемь строк, статусы почты и KYC.
Загрузка, ошибка с повтором, пустой список и пустой поиск имеют отдельные состояния.
Админ-панель не меняет клиентов, банковские данные или статус KYC.
Отсутствие настроек backend отображается как ошибка доступности, а не как демо-данные.
