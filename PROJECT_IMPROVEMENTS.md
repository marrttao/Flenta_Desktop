# Звіт про аналіз і виправлення

Дата: 28 жовтня 2026 року.

## Обсяг

Переглянуто структуру React/Vite-проєкту, маршрутизацію, авторизацію,
HTTP-клієнт, банківські утиліти, сховище, локалізацію, модальні вікна,
сповіщення та конфігурацію перевірок. Внесено локальні зміни без зміни
API компонентів, маршрутів, залежностей або контрактів банківських запитів.
Це цільовий огляд, а не повний аудит усіх сценаріїв застосунку.

## Що виправлено

### 1. BasicModal: фокус і доступність

Файл: `src/components/ui/Modals/BasicModal/components/BasicModal.tsx`.

- Ефект відкриття/закриття відокремлено від підписки на клавіатуру.
  Раніше новий `onClose` під час повторного рендеру запускав очищення ефекту,
  повертав фокус і повторно запам'ятовував його всередині вікна. Тепер зміна
  обробника не перевстановлює початковий фокус і не скидає блокування прокрутки.
- Для початкового фокуса й Tab використовується одна перевірка доступних
  елементів. Вона відкидає приховані, вимкнені, inert-елементи та елементи
  з від'ємним tabIndex, враховуючи вимкнення через fieldset.
- Tab залишається у вікні, навіть якщо доступних кнопок немає або фокус
  перебуває на самому контейнері чи поза вікном.
- Додано `role="dialog"`, `aria-modal` і зв'язок із заголовком через `useId`.
- Кнопка закриття явно має `type="button"`.

### 2. ConfirmModal: переклади стандартних кнопок

Файл: `src/components/ui/Modals/ConfirmModal/components/ConfirmModal.tsx`.

Значення `Confirm` і `Cancel` у параметрах раніше робили переклад через `??`
недосяжним. Тепер без переданого тексту використовуються переклади поточної
мови; явно переданий текст зберігається. Спрощено вибір CSS-класу варіанта,
прибрано невикористаний імпорт.

### 3. ToastItem: таймер і кнопка закриття

Файл: `src/components/ui/Toast/components/ToastItem/ToastItem.tsx`.

Ефект таймера тепер залежить від стану виходу, який він перевіряє.
Таймер очищається при переході до анімації виходу та при демонтуванні.
Зайвий ref замінено локальним ідентифікатором таймера.
Кнопка закриття отримала локалізований `aria-label`.

### 4. HTTP-клієнт: стійкість до некоректних відповідей

Файл: `src/features/auth/api/httpClient.js`.

Помилкова відповідь із JSON `null` раніше спричиняла TypeError замість ApiError.
Тепер JSON перевіряється до читання полів, а повідомлення валідації збираються
лише з рядків. HTTP-статус зберігається і для некоректного JSON/HTML, що
дозволяє авторизації розпізнати 401. Опційний доступ до `import.meta.env`
дозволяє перевіряти модуль штатним Node test runner; у Vite конфігурація
базової URL працює як раніше.

### 5. Форматування грошей

Файл: `src/features/banking/utils/banking.js`.

`Intl.NumberFormat` створюється один раз на модуль замість кожного виклику
`money`. Локаль uk-UA, валюта UAH і правила форматування збережені.

### 6. Тести на Windows

Файли: `package.json`, `tests/httpClient.test.mjs`.

Команду змінено на `node --test`: попередній шаблон `tests/*.test.mjs`
не розгортався у поточному Windows/Node 20 середовищі. Додано чотири тести:
некоректні тіла помилок, повідомлення валідації, заголовки/JSON/204 і
мережеві збої. Наявні чотири банківські тести залишено.
